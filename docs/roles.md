# 역할과 인계

PM은 사용자가 수행할 흐름을 정리하고, 이를 확인 가능한 작은 이슈로 나눈다. 기술 선택과 실행 환경을 조정하며 프론트엔드와 백엔드의 연결, 검토 의견, 재작업을 관리한다. 문서 작성과 검토도 PM의 기여에 포함된다.

프론트엔드 담당자는 로그인 상태, 질문·응답 화면, 대화 조회와 로딩·오류 안내를 맡는다. 인증 백엔드 담당자는 Google 로그인, 로컬 사용자 연결, JWT와 접근 제어를 맡는다. 채팅·데이터 백엔드 담당자는 서버의 채팅 처리, 외부 AI 서비스 호출, 대화 저장·조회와 운영 기록을 맡는다. 두 백엔드 담당자는 인증된 사용자 정보를 연결하고 사용자별 데이터 경계를 함께 확인한다.

작업을 넘길 때는 변경한 동작과 요청·응답 형식, 필요한 설정, 확인 방법과 결과를 이슈 또는 PR에 적는다. 연결 부분이 바뀌면 영향을 받는 담당자와 함께 화면·서버 동작을 확인한다. 각 담당자가 먼저 자신의 변경을 확인하고, PM이 요구사항과 통합 결과를 검토한다. 문제가 발견되면 담당자가 수정하고 같은 흐름을 다시 확인한다. 별도 품질 담당자는 두지 않는다.

이슈는 요구한 동작이 재현되고, 정상·실패 상황의 확인 결과가 남고, 관련 문서와 다른 담당자에게 필요한 정보가 갱신되면 완료한다.
