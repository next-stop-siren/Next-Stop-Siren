# 역할과 인계

PM은 요구 흐름을 작은 이슈와 완료 기준으로 정리하고 공통 설정과 통합 결과를 검토한다. 프론트엔드 담당자는 로그인 상태와 채팅 화면·API 연결을 맡는다. 인증 백엔드 담당자는 Google OIDC 로그인 결과 검증, 로컬 사용자 연결, 접근·갱신 JWT와 접근 제어를 맡는다. 채팅·데이터 백엔드 담당자는 외부 AI 연결과 사용자별 대화 저장·조회를 맡는다. 두 백엔드 담당자는 인증된 사용자 정보와 데이터 경계를 함께 확인한다.

작업을 넘길 때 변경한 동작, 요청·응답 계약, 필요한 설정, 실행한 확인과 결과를 이슈나 PR에 남긴다. 경계가 바뀌면 영향을 받는 담당자와 함께 확인한다. 담당자가 자신의 변경을 먼저 검사하고 PM과 관련 담당자가 검토한다. 결함은 담당자가 수정하고 같은 흐름을 다시 확인한다.

이슈는 요구 동작이 재현되고 정상·실패 확인 결과가 남으며 관련 문서와 인계 정보가 갱신되면 완료한다.
