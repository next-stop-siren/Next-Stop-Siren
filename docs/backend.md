# 백엔드 지침

FastAPI 서버는 인증, 입력 검사, 채팅 처리, 외부 AI 서비스 연결, PostgreSQL 저장을 구분해 작성한다. 화면과 합의한 요청·응답 형식을 사용하고, 오류는 사용자가 이해할 수 있게 전달하되 내부 정보는 노출하지 않는다.

Google OIDC 로그인 결과를 서버에서 검증한다. 첫 로그인에서는 검증된 외부 식별자를 로컬 사용자에 생성·연결하고, 이후에는 같은 사용자를 찾는다. 애플리케이션의 접근·갱신 JWT는 서명과 만료를 확인한다. 갱신 토큰은 로그아웃이나 폐기 후 재사용할 수 없게 처리한다. 보호된 요청은 인증 여부를 확인하고, 대화의 조회·변경은 서버에서 확인한 사용자 소유권으로 제한한다.

채팅 요청은 서버에서 입력을 검사한다. 이어지는 대화에 필요한 이전 문맥을 AI 요청에 포함하고, 질문과 응답을 사용자별로 저장·조회한다. 대화 기록에는 해당 사용자, 생성 시각, 질문과 답변을 확인할 수 있어야 한다. 외부 AI 요청에는 시간 제한과 실패 처리를 둔다. AI 호출 실패나 시간 초과, DB 저장 실패가 나면 성공으로 가장하지 않고 일관된 오류를 돌려준다. 저장과 응답의 순서를 정해 부분 실패 때 기록과 화면이 어긋나지 않게 한다.

완료 시 신규·기존 로그인, 만료·위조된 자격 증명, 갱신 토큰 폐기, 비인증 요청, 다른 사용자 기록 접근, 정상 대화, AI 시간 초과·실패와 DB 실패를 확인한다.
