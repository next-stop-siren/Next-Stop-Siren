# 프론트엔드 지침

React 컴포넌트는 화면과 입력을 담당하고, API 호출·응답 변환은 별도 모듈로 둔다. TypeScript 타입은 화면 상태와 합의한 API 계약에 맞춘다. 기능별 코드는 `src/features/<기능>/`에 모으고 공유 UI는 `src/components/`, 공통 API 코드는 `src/lib/`처럼 역할이 드러나게 배치한다. 실제 폴더를 만들 때 사용처가 없는 추상 계층은 만들지 않는다.

컴포넌트 파일은 `PascalCase.tsx`, 훅은 `useName.ts`, 일반 함수·변수는 `camelCase`, 타입은 `PascalCase`를 쓴다. 로그인 전에는 보호된 채팅·기록을 표시하지 않는다. 질문 입력, 답변, 기록 조회에는 비어 있음·진행 중·실패 상태를 표현하고, 실패 후 입력을 유지해 다시 시도할 수 있게 한다. 빈 질문은 화면에서 안내하고 서버 검사도 유지한다. 사용자 및 외부 서비스에서 온 글은 신뢰하지 않고 텍스트로 렌더링한다. 키보드 접근, 입력 이름, 초점, 오류 안내와 좁은 화면을 확인한다. 브라우저 코드에 서버 비밀값을 넣지 않는다.

PR 전에는 저장소에 마련된 포맷, ESLint, TypeScript 검사와 관련 테스트를 실행하고 결과를 남긴다. 자동 포맷이 많은 파일을 바꾸면 기능 변경과 구분해 검토한다. 테스트 기준은 [품질 지침](quality.md)을 따른다.
