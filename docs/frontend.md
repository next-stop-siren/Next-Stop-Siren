# 프론트엔드 지침

React 컴포넌트는 화면과 입력을 다루고, 서버 요청과 응답 해석은 별도 함수로 모은다. TypeScript로 화면에 필요한 props, 상태, 요청·응답의 기본 형식을 적는다. `useState`로 로그인 상태와 질문 전송의 로딩·성공·오류를 표현한다. 서버와 연결할 때는 담당자끼리 확인한 요청·응답 형식을 사용한다.

로그인 전에는 보호된 채팅과 기록을 보여 주지 않는다. 질문 입력, 답변 표시, 대화 조회에 빈 화면·진행 중·실패 상태를 마련한다. 빈 질문은 화면에서 안내하고 서버의 입력 검사도 유지한다. 실패 뒤에는 사용자가 내용을 잃지 않고 다시 시도할 수 있게 한다.

사용자 입력과 챗봇 응답은 신뢰할 수 없는 글로 취급해 안전하게 표시한다. 임의 HTML 실행을 피하고, 키보드 조작·초점 이동·입력 이름·오류 안내·좁은 화면을 확인한다. 서버용 비밀값이나 외부 AI 서비스의 자격 증명을 브라우저 코드에 넣지 않는다.

완료 시 로그인 전후 화면, 질문 성공과 실패, 사용자별 기록 조회를 재현하고 확인 결과를 PR에 남긴다.
